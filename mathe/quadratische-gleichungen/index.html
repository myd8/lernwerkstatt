Quadratische Gleichungen

Unterricht vom 26. November 2026

Wurzelziehen

Steht x² allein auf einer Seite, entscheidet die Zahl auf der anderen Seite über die reellen Lösungen.

  • x² = 16 hat zwei Lösungen, x = 4 und x = −4. Beide Zahlen ergeben beim Quadrieren 16.
  • x² = 0 hat genau eine Lösung, x = 0.
  • x² = −9 hat keine reelle Lösung. Das Quadrat jeder reellen Zahl ist größer als oder gleich 0.

Ausklammern und Satz vom Nullprodukt

Stehen nur Terme mit x auf einer Seite und 0 auf der anderen, kannst du x ausklammern. Ein Produkt ist 0, wenn mindestens einer seiner Faktoren 0 ist.

5x² + 20x = 0
5x(x + 4) = 0
x = 0 oder x + 4 = 0
L = {−4, 0}

Beim Teilen durch x würde die Lösung x = 0 verloren gehen.

Die p-q-Formel

Bringe die Gleichung in die Form x² + px + q = 0. Steht vor x² ein Faktor ungleich 1, teile die ganze Gleichung zuerst durch diesen Faktor. Lies p und q mit ihren Vorzeichen ab.

x1,2 =−p2± (p2)2−q

Der Ausdruck unter der Wurzel bestimmt die Anzahl der reellen Lösungen. Ist er positiv, gibt es zwei. Bei 0 gibt es eine. Ist er negativ, gibt es keine.

Beispiel mit p = −8 und q = 15

x² − 8x + 15 = 0
x = 4 ± √(16 − 15) = 4 ± 1
L = {3, 5}

Üben

Bestimme zuerst p und q. Löse anschließend beide Gleichungen und prüfe deine Ergebnisse.

  1. x² − 14x + 24 = 0
  2. x² − 8x − 65 = 0
Rechenwege anzeigen
  1. x = 7 ± √(49 − 24) = 7 ± 5. Daraus folgt L = {2, 12}.
  2. Hier ist q = −65. Deshalb gilt x = 4 ± √(16 + 65) = 4 ± 9. Daraus folgt L = {−5, 13}.
